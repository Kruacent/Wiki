# SCP-3114

<div style={{ display: 'flex', alignItems: 'center', gap: '15px', marginBottom: '1rem' }}>
  <div>
    <span style={{ backgroundColor: '#FF0000', color: 'white', padding: '4px 8px', borderRadius: '4px', fontSize: '0.8rem', fontWeight: 'bold', textTransform: 'uppercase' }}>SCP</span>
  </div>
</div>

Un squelette qui se déguise avec la peau de ses victimes. Il marche parmi les humains, il leur parle, et il attend le bon moment. Sur Kruaçent, il est **rare** on ne le croise que si quelqu'un passe dans SCP-914.

## En bref

| | |
| :--- | :--- |
| **Vie sur Kruaçent** | **+25 %** par rapport au jeu de base |
| **En début de partie** | **Jamais** : le tirage des SCP du serveur ne le propose pas |
| **Comment il apparaît** | Un SCP-096 passé dans SCP-914 en **1:1** |
| **Variantes possibles** | [Paper](/docs/kruacent-exiled/custom-role/SCP/Paper) ou [Petit](/docs/kruacent-exiled/custom-role/SCP/Small), comme tous les SCP |

## Ce qui change sur Kruaçent

- **Il n'apparaît pas au début.** Sur Kruaçent, les SCP sont tirés parmi SCP-049, 079, 096, 106, 173, 939 et les SCP du serveur ([SCP-035](/docs/kruacent-exiled/custom-role/SCP/SCP035), [SCP-049-C](/docs/kruacent-exiled/custom-role/SCP/SCP049C)). SCP-3114 n'en fait pas partie.
- **SCP-914 est sa seule porte d'entrée.** Un SCP-096 qui passe dans la machine en 1:1 peut ressortir en SCP-3114. Et lui-même peut ressortir en autre chose :

| Réglage | Il ressort en… |
| :--- | :--- |
| 1:1 | SCP-096 |
| Very Fine | SCP-173 |

Ça ne marche pas à tous les coups : la plupart du temps, c'est une fois sur deux. Voir [SCP-914](/docs/kruacent-exiled/miscellaneous/914).

- **Il a un quart de vie en plus**, comme tous les SCP.

## Les events qui le touchent

| Event | Ce qui lui arrive |
| :--- | :--- |
| [Impostor](/docs/kruacent-exiled/global-event/Impostor) | Tout le monde change d'apparence. Pour lui, c'est presque des vacances : personne ne ressemble plus à personne |
| [HealSCPM](/docs/kruacent-exiled/global-event/middle-event/HealSCP) | S'il est presque mort (comme tous les autres SCP), il remonte à la moitié de sa vie |
| [Kaboom](/docs/kruacent-exiled/global-event/Kaboom) | Les grenades des portes piégées lui font moitié moins mal |

## Contre lui : ce qui marche

| Objet | Pourquoi |
| :--- | :--- |
| [Proximity Grenade](/docs/kruacent-exiled/custom-item/proximity-grenade) | Chaque trait a la couleur du **vrai** rôle. Un « Scientifique » avec un trait rouge, ce n'est pas un Scientifique |
| [Cocktail Molotov](/docs/kruacent-exiled/custom-item/cocktail-molotov) | 40 PV par seconde aux SCP, déguisés ou non |
| [M-Scan](/docs/kruacent-exiled/custom-item/m-scan) | Il annonce le rôle de ce qui passe devant. Les déguisements n'y font rien |

## Contre lui : ce qui ne marche pas

| Objet | Pourquoi |
| :--- | :--- |
| [TP Grenade](/docs/kruacent-exiled/custom-item/teleportation-grenade) | SCP-3114 n'est **pas** téléporté |
| [Presse-Purée](/docs/kruacent-exiled/custom-item/presse-purée) | Trois fois moins de dégâts aux SCP |

## Conseils

**Si vous jouez contre lui :**
- Si quelqu'un vient de passer dans SCP-914 en étant SCP-096, méfiez-vous de tous les humains un peu trop gentils.
- Un « coéquipier » qui ne répond pas à la radio, c'est suspect.

**Si vous le jouez :**
- Vous êtes rare : les humains ne s'attendent pas à vous. Profitez-en.
- Pendant Impostor, tout le monde est déguisé. Vous êtes chez vous.

## Rapport d'incident : « Le nouveau »

> **Sgt. Alex :** "Capitaine, j'ai trouvé un Scientifique perdu en Heavy. Il est très sympa. Il m'a fait un câlin."
>
> **Cpt. Romain :** "Un câlin ?"
>
> **Sgt. Alex :** "Un long câlin. Il est un peu maigre, aussi."
>
> **Sgt. Dorian :** "Alex, SCP-096 est passé dans SCP-914 il y a cinq minutes."
>
> **Sgt. Alex :** "Et ?"
>
> **Sgt. Caedit :** *[lance une Proximity Grenade aux pieds du « Scientifique »]*
>
> *[Un trait rouge vif relie la grenade au Scientifique.]*
>
> **Sgt. Caedit :** "Les Scientifiques n'ont pas de trait rouge."
>
> *[Le « Scientifique » lâche Alex. Le Sergent Caedit tire trois fois, très vite, très juste.]*
>
> **Sgt. Alex :** "…Il me faisait un câlin parce qu'il voulait ma peau ?"
>
> **Sgt. Caedit :** "Littéralement."
