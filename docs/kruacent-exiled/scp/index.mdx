# SCP

Les SCP de Kruaçent ressemblent à ceux du jeu de base… en plus costauds, avec des variantes, et entourés d'objets bizarres qui changent les combats. Chaque fiche regroupe **tout** ce qu'il faut savoir sur un SCP : ce qui change ici, les events qui le touchent, et ce qui marche contre lui.

## Les fiches

| SCP | En deux mots |
| :--- | :--- |
| [SCP-049](/docs/kruacent-exiled/scp/scp-049) | Le docteur. Deux zombies limités et une version canibale. |
| [SCP-096](/docs/kruacent-exiled/scp/scp-096) | Ne regardez pas son visage, surtout pendant Speed. |
| [SCP-106](/docs/kruacent-exiled/scp/scp-106) | Papi, plus résistant à plusieurs, sans pitié pour le dernier humain. |
| [SCP-173](/docs/kruacent-exiled/scp/scp-173) | La statue. Elle garde la Gambling Room et devient folle pendant Speed. |
| [SCP-939](/docs/kruacent-exiled/scp/scp-939) | La chasseuse qui entend tout. Encore plus résistante quand elle n'est pas seule. |
| [SCP-3114](/docs/kruacent-exiled/scp/scp-3114) | Le squelette déguisé. Il n'apparaît que via SCP-914. |
| [SCP-035](/docs/kruacent-exiled/custom-role/SCP/SCP035) | Le masque. Un SCP propre au serveur, décrit dans les Custom Roles. |

## Ce qui change pour tous les SCP

| | |
| :--- | :--- |
| **Vie** | **+25 %** de vie max pour tous les SCP (pas les zombies) |
| **Quand ils sont plusieurs** | SCP-939 monte à **+50 %**, SCP-106 à environ **+37 %**, SCP-049 revient à peu près à sa vie normale |
| **Zombies** | SCP-049 ne peut pas avoir plus de **2 zombies** en vie |
| **Choix du SCP** | Chaque joueur règle ses préférences dans les paramètres du serveur. Voir [l'attribution des SCP](/docs/articles/CustomRole#attribution-des-scp) |
| **SCP-914** | Un SCP qui passe dans SCP-914 peut ressortir en **un autre SCP**. Voir [SCP-914](/docs/kruacent-exiled/miscellaneous/914) |

Le détail est sur la page [Équilibrage des SCP](/docs/kruacent-exiled/miscellaneous/equilibrage-scp).

## Les variantes

Certains SCP apparaissent avec un rôle spécial. Elles sont décrites dans les [Custom Roles](/docs/articles/CustomRole) :

- [SCP-049-C](/docs/kruacent-exiled/custom-role/SCP/SCP049C) : un SCP-049 qui consomme les corps pour s'améliorer.
- [Ultra SCP-939](/docs/kruacent-exiled/custom-role/SCP/Ultra) : une SCP-939 qui sait combien d'humains se cachent dans chaque zone.
- [Frozen](/docs/kruacent-exiled/custom-role/SCP/Frozen) : un SCP-173 qui laisse du SCP-244 derrière lui.
- [Paper](/docs/kruacent-exiled/custom-role/SCP/Paper) et [Petit](/docs/kruacent-exiled/custom-role/SCP/Small) : des SCP très fins, ou très petits.
- [SCP-035](/docs/kruacent-exiled/custom-role/SCP/SCP035) : un SCP à part entière, propre au serveur.
