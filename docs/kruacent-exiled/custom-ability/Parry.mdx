# Contre

Le **Contre** est une capacité **active** : vous devenez invincible pendant **une demi-seconde**. C'est court, très court. Le bon timing, c'est tout.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Invincible pendant 0.5 secondes |
| **Description (Anglais)** | Invincible for 0.5 seconds |
| **Durée** | 0,5 seconde |
| **Temps de recharge** | 60 secondes |

---

## Obtention

[SCP-049-C](/docs/kruacent-exiled/custom-role/SCP/SCP049C) l'obtient en choisissant l'amélioration **Parry** à son deuxième palier.
