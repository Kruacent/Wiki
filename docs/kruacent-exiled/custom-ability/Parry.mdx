# Contre

Le **Contre** est une capacité **active** : à l'activation, l'utilisateur devient invincible pendant **0,5 seconde**.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Nom (Français)** | Contre |
| **Description (Français)** | Invincible pendant 0.5 secondes |
| **Description (Anglais)** | Invincible for 0.5 seconds |
| **Temps de recharge** | 120 secondes |
| **Durée** | 0,5 seconde |

## Obtention

Cette capacité est prévue comme amélioration de palier 2 de [SCP-049-C](/docs/kruacent-exiled/custom-role/SCP/SCP049C), sous le nom « Deflect Damages ».

:::warning Version actuelle
Choisir l'amélioration « Deflect Damages » ne donne pas cette capacité dans la version actuelle, et son effet de blocage des dégâts n'est pas activé : cette amélioration ne fait rien pour l'instant.
:::

## Note de la Fondation

L'entité est capable de se rendre intouchable pendant une fraction de seconde. Les équipes d'intervention doivent éviter de tout tirer au même instant.
