# AirStrike

<AbilityIcon src={Icone} alt="Icône AirStrike" />

L'AirStrike est une abilité **active** conçue pour bombarder une zone. Lors de son activation, une lumière rouge simulant du fumigène apparaît dans la zone de bombardement puis, au bout de 1,5 seconde, une explosion a lieu dans la zone.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Ne l'utilise pas trop sinon ton coop sera pas content |
| **Description (Anglais)** | Don't overuse it or your co-op will not be happy |
| **Temps de recharge** | 60 secondes |

---

## Mécanique détaillée

L'utilisation de cette abilité se décompose en plusieurs phases :

1. **Pré-requis :** L'utilisation de l'abilité [SetPosition](SetPosition) est requise pour sélectionner la zone de bombardement. Si aucun point n'est enregistré, utiliser AirStrike enregistre directement votre position actuelle comme point (sans lancer de frappe).
2. **Activation :** Une fois que la position est sauvegardée, vous pouvez désormais utiliser AirStrike.
3. **Pré-Impact :** Une lumière rouge simulant du fumigène apparaît durant 1,5 seconde (la lumière est visible pour tout le monde). Si un obstacle se trouve à moins d'un mètre au-dessus du point, l'abilité échoue avec le message *"Quelque chose gêne"*.
4. **Explosion :** Après 1,5 seconde, une grenade est lâchée juste au-dessus du point et explose dès qu'elle touche une surface.
