# Set Position

<AbilityIcon src={Icone} alt="Icône Set Position" />

Set Position est une abilité **active** conçue pour selectionné une zone.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Selectionne la position pour une autre abilité |
| **Description (Anglais)** | Select the current position for another ability |
| **Temps de recharge** | 5 secondes |

---

## Mécanique détaillée

La position sélectionnée est valable uniquement dans un rayon de 25 mètres : si le joueur s'éloigne à plus de 25 mètres, la position est supprimée.

Tant qu'un point est enregistré, le nom de la capacité affiche la **distance** qui vous en sépare (par exemple *SetPosition (12.4m)*). Pratique pour savoir si vous êtes encore dans les 25 mètres.

Pas besoin de penser à l'utiliser avant : si vous lancez [AirStrike](AirStrike) ou la [Téléportation](Téléportation) sans point enregistré, votre position actuelle est enregistrée à la place.
