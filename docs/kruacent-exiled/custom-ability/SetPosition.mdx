# Set Position

<AbilityIcon src={Icone} alt="Icône Set Position" />

Set Position est une abilité **active** conçue pour selectionné une zone.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Selectionne la position pour une autre abilité |
| **Description (Anglais)** | Select the current position for another ability |
| **Temps de recharge** | 5 secondes |

---

## Mécanique détaillée

La position selectionné est valable uniquement 25 mètres, si le joueur s'éloigne à plus de 25 mètres la position est supprimé.
