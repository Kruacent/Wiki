# Recharge tactique

La **Recharge tactique** est une capacité **active** du [Supresseur](/docs/kruacent-exiled/custom-role/ChaosInsurgency/Suppressor). Activez-la, puis tuez quelqu'un dans les **5 secondes** avec votre **Logicer** en main : le chargeur se remplit d'un coup. Une seule recharge par activation.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Recharge ton Logicer quand tu tues un joueur |
| **Description (Anglais)** | Reload your Logicer when killing a player |
| **Durée** | 5 secondes |
| **Temps de recharge** | 120 secondes |

---

## Conseils

- Activez-la juste avant d'achever un ennemi blessé : vous repartez avec un chargeur plein pour le suivant.
