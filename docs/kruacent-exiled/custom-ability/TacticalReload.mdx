# Recharge tactique

La **Recharge tactique** est une capacité **active**. Après l'activation, le joueur a **5 secondes** pour tuer un joueur en tenant un **Logicer** en main : le chargeur du Logicer est alors rempli entièrement, instantanément. Cela ne marche qu'une fois par activation.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Nom (Français)** | Recharge tactique |
| **Description (Français)** | Recharge ton Logicer quand tu tues un joueur |
| **Description (Anglais)** | Reload your Logicer when killing a player |
| **Temps de recharge** | 120 secondes |
| **Durée** | 5 secondes |
| **Condition** | Tuer un joueur avec le Logicer en main pendant la durée |
| **Effet** | Chargeur du Logicer rempli au maximum |

:::note
La capacité ne fonctionne que pour le rôle [Supresseur](/docs/kruacent-exiled/custom-role/ChaosInsurgency/Suppressor).
:::

### Conseils

- Activez la capacité juste avant d'achever un ennemi blessé : vous repartez avec un chargeur plein pour la cible suivante.
