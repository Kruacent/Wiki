# Spear

**Spear** est une capacité **active à distance**. N'ayant pas accès aux armes à feu, la Red Mist peut utiliser cette technique pour projeter une puissante attaque perforante droit devant elle, idéale pour surprendre les ennemis qui tentent de fuir.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Projette une attaque à distance infligeant de lourds dégâts à l'impact. |
| **Description (Anglais)** | Launches a powerful ranged attack dealing heavy damage on impact. |
| **Dégâts** | 200 PV |
| **Portée** | Projectile en ligne droite |
| **Temps de recharge** | Aucun |

---

## Mécanique détaillée

Cette compétence vous donne une solution redoutable pour engager les adversaires à distance.

### 1. Conditions d'utilisation
- **Arme en main :** Vous devez impérativement tenir votre arme signature (**The Mimicry** / *SCP-1509*) en main pour lancer la capacité.
- **État d'E.G.O :** Cette capacité est utilisable à tout moment, que votre E.G.O soit activé ou non.

### 2. Impact en combat
- Un projectile rapide est projeté dans la direction exacte où vous regardez.
- Tout ennemi touché subit **200 points de dégâts**, ce qui est suffisant pour éliminer instantanément la majorité des humains s'ils n'ont pas de protection maximale, ou pour entamer sévèrement la santé d'un SCP.
