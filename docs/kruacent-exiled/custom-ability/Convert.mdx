# Conversion

<AbilityIcon src={Icone} alt="Icône Conversion" />

La **Conversion** est une abilité **active** conçue pour transformer les instances "SCP-049-2" en humain.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Converti un zombie à la bonne foi |
| **Description (Anglais)** | Convert a zombie to your team |
| **Temps de recharge** | 60 secondes |

---

## Mécanique détaillée

La conversion est actuellement sous forme d'un [COM-15](https://en.scpslgame.com/index.php?title=COM-15). Les tirs touchant les zombies, permet la transformation immédiate.
