# Diabète

Le diabète est une abilité **passive** permettant d'avoir l'effet de [SCP-207](https://en.scpslgame.com/index.php?title=SCP-207).

---

## Mécanique détaillée

Contrairement à l'utilisation d'un [SCP-207](https://en.scpslgame.com/index.php?title=SCP-207) classique, l'utilisation d'un [SCP-1853](https://en.scpslgame.com/index.php?title=SCP-1853) avec cet effet est possible.

Cette abilité peut être enlever avec un [SCP-500](https://en.scpslgame.com/index.php?title=SCP-500).
