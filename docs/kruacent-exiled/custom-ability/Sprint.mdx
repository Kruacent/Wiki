# Sprint

Le **Sprint** est une capacité **active** : pendant **5 secondes**, vous courez beaucoup plus vite. Ça se cumule avec les autres bonus de vitesse que vous avez déjà.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Cours plus vite pendant 5s |
| **Description (Anglais)** | You run faster for a short time |
| **Durée** | 5 secondes |
| **Temps de recharge** | 95 secondes |

---

## Conseils

- Cinq secondes, c'est court : gardez-le pour fuir, pas pour faire le tour de la Light.
