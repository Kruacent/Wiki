# Sprint

Le **Sprint** est une capacité **active** : à l'activation, le joueur reçoit un bonus de vitesse de déplacement de **+50** pendant **5 secondes**. S'il avait déjà un bonus de vitesse, les 50 points s'ajoutent à son bonus actuel puis sont retirés au bout de 5 secondes.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Nom (Français)** | Sprint |
| **Description (Français)** | Cours plus vite pendant 5s |
| **Description (Anglais)** | You run faster for a short time |
| **Temps de recharge** | 95 secondes |
| **Durée** | 5 secondes |
| **Bonus de vitesse** | +50 |

### Conseils

- Gardez le Sprint pour fuir ou pour traverser une zone dangereuse : il ne dure que 5 secondes pour plus d'une minute et demie de recharge.

## Note de la Fondation

Le sujet est capable d'accélérer brièvement bien au-delà de ses capacités habituelles. Les essais montrent que l'effort ne peut pas être répété avant plusieurs minutes.
