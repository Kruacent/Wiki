# Checkpoints restants

**Checkpoints restants** est une capacité **passive** qui ne sert qu'à afficher une information : elle apparaît dans la liste des capacités du [Zone Manager](/docs/kruacent-exiled/custom-role/Scientist/ZoneManager) et indique combien de checkpoints il lui reste à ouvrir pour obtenir sa promotion.

Elle s'affiche sous la forme :

> **FR :** *Checkpoints restant : 3/4*

> **EN :** *Remaining Checkpoints : 3/4*

Le « s » disparaît quand il ne reste qu'un checkpoint. La ligne disparaît quand tous les checkpoints sont ouverts.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Type** | Information (aucune action) |
| **Total de checkpoints** | 4 |
