# Checkpoints restants

**Checkpoints restants** est une capacité **passive** qui ne fait rien d'autre que vous rappeler votre mission : elle compte les checkpoints que le [Zone Manager](/docs/kruacent-exiled/custom-role/Scientist/ZoneManager) doit encore ouvrir pour obtenir sa promotion.

> **FR :** *Checkpoints restant : 3/4*

> **EN :** *Remaining Checkpoints : 3/4*

Quand tous les checkpoints sont ouverts, la ligne disparaît. Promotion validée.
