# Fabrication de Grenade

La **Fabrication de Grenade** est une capacité **active** : un peu de bricolage, et hop, une grenade explosive toute neuve dans votre inventaire. Si vos poches sont pleines, elle tombe à vos pieds (attention à ne pas l'oublier par terre).

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Tu fabriques une grenade |
| **Description (Anglais)** | You create a HE Grenade |
| **Temps de recharge** | 100 secondes |
