# Fabrication de Grenade

La **Fabrication de Grenade** est une capacité **active** : à chaque activation, le joueur reçoit une grenade explosive (HE) standard. Si son inventaire est plein, la grenade apparaît à ses pieds.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Nom (Français)** | Fabrication de Grenade |
| **Description (Français)** | Tu fabriques une grenade |
| **Description (Anglais)** | You create a HE Grenade |
| **Temps de recharge** | 100 secondes |
| **Objet donné** | 1 grenade HE |

### Conseils

- Gardez une place libre dans votre inventaire : sinon la grenade tombe au sol et vous devez la ramasser.
