# Grand saut

Le **Grand saut** est une capacité **active** qu'on allume et qu'on éteint. Allumée, elle vous fait sauter beaucoup plus haut, assez pour grimper là où personne ne vous attend. La redescente, elle, reste normale : pas de chute en douceur.

Le nom passe en **vert** quand le grand saut est allumé, en **rouge** quand il est éteint.

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Nom (Français)** | Active/désactive grand saut |
| **Nom (Anglais)** | Toggle Big Jump |
| **Temps de recharge** | 2 secondes |

---

## Obtention

C'est l'amélioration « Jump » de [SCP-049-C](/docs/kruacent-exiled/custom-role/SCP/SCP049C) à son premier palier, qui promet de sauter assez haut pour atteindre la Gate B. Une fois débloqué, le grand saut est éteint : pensez à l'allumer.
