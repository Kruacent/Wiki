# Alzheimer

L'Alzheimer est une abilité **passive** téléportant le joueur dans une salle aléatoire dans la même zone. 

---

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Je suis vieux |
| **Description (Anglais)** | I'm old |
| **Temps de recharge** | 5 à 10 minutes |

---

## Mécanique détaillée

Toutes les 5 à 10 minutes, le joueur se fait téléporter aléatoirement dans une salle de la même zone. Lors de la téléportation le joueur se fait flasher, et il est invisible durant un court instant après sa téléportation.

Cette abilité peut être enlever avec un [SCP-500](https://en.scpslgame.com/index.php?title=SCP-500).
