# Tir allié

Sur Kruaçent, le **tir allié** n'est pas fixe : il peut s'activer ou se désactiver pendant la partie. Vérifiez avant de tirer à travers votre équipe.

## Ce qui peut le changer

| Moment | Ce qui se passe |
| :--- | :--- |
| **Début de partie** | Le tir allié est activé. |
| **Lancement de l'ogive Alpha** | Une chance sur deux que le tir allié soit réactivé, s'il avait été coupé. |
| **Mort d'un SCP** | Une chance sur cinq que le tir allié change d'état (activé ↔ désactivé). |
| **Ouverture d'une porte** | Très rarement, le tir allié change d'état. Oui, en ouvrant une porte. |

Bref : la partie commence avec le tir allié, et la chance décide ensuite.

## Conseils

- Dans le doute, ne tirez pas à travers un allié.
- Un SCP vient de mourir ? Le tir allié a peut-être changé.
