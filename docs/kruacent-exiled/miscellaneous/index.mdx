# Miscellaneous

Cette catégorie regroupe les mécaniques du serveur qui ne sont ni des objets, ni des rôles, ni des capacités, ni des Global Events :

* [Gambling Coin](/docs/kruacent-exiled/miscellaneous/gambling-coin) : lancer une pièce déclenche un effet aléatoire, positif ou négatif.
* [Gambling Room](/docs/kruacent-exiled/miscellaneous/gambling-room) : une machine qui échange l'objet tenu en main contre un objet aléatoire.
* [SCP-914](/docs/kruacent-exiled/miscellaneous/914) : les effets ajoutés quand un joueur ou un objet passe dans SCP-914.
