# Lancement de la partie

Sur Kruaçent, la partie ne démarre pas toute seule : il faut que les joueurs **votent** pour la lancer. Et pour voter, rien de plus simple : **parlez dans votre micro** pendant que vous êtes dans le lobby.

## Le vote

- Dès que vous parlez dans le lobby, votre vote est compté.
- Quand le **seuil de votes** est atteint, la partie peut démarrer.
- Le compteur s'affiche à l'écran, avec la liste des votants : *Votes (4/15)*, par exemple.

### Le seuil de votes

Le seuil n'est pas fixe : c'est un **admin présent** qui le règle selon le nombre de joueurs connectés. En général, il le cale sur tout le monde : **15 joueurs connectés = 15 votes**. Comme ça, la partie ne démarre pas sans quelqu'un qui est encore en train de chercher son micro.

- Vous avez parlé par erreur ? Tapez **`.rv`** dans la console du jeu pour retirer votre vote.
- Si un votant quitte le serveur, son vote est retiré.

## Ce qu'on voit dans le lobby

- La **version** du serveur et depuis combien de **minutes** le lobby attend.
- Si votre écran n'est pas en **16:9**, un avertissement rouge s'affiche : certains textes du serveur risquent d'être mal placés.
