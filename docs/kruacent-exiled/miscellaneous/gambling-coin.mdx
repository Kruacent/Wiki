# Gambling Coin

Sur Kruaçent, **lancer une pièce** déclenche un effet aléatoire. Un effet sur deux est positif, l'autre négatif. Cela concerne toutes les pièces normales (pas les objets personnalisés, sauf la [Pièce compressée](/docs/kruacent-exiled/custom-item/compressed-coin)).

## Règles

| Règle | Valeur |
| :--- | :--- |
| **Chance d'un effet positif** | 50 % |
| **Chance d'un effet négatif** | 50 % |
| **Utilisations par pièce** | 1 : la pièce disparaît après le lancer (*"no more coin"*) |
| **Délai entre deux lancers** | 3 secondes (*"You must wait before flipping again"*) |

- Une fois positif ou négatif décidé, l'effet est tiré au sort selon son **poids** : plus le poids est élevé, plus l'effet est fréquent. La chance indiquée dans les tableaux est la chance de l'effet **une fois la catégorie tirée** ; pour la chance réelle sur un lancer, divisez par 2.
- Le message de l'effet s'affiche à l'écran pendant 5 secondes.
- L'[Ultimate Lucky Student](/docs/kruacent-exiled/custom-role/Human/UltimateLuckyStudent) obtient toujours un effet positif.
- La [Pièce compressée](/docs/kruacent-exiled/custom-item/compressed-coin) déclenche entre 10 et 30 effets d'un coup, chacun tiré avec les mêmes règles.

:::note Valeurs par défaut
Le nombre d'utilisations et le délai sont les valeurs par défaut du code. Le serveur peut les modifier dans sa configuration.
:::

### Où trouver des pièces ?
- Les pièces du jeu de base, dans la facilité.
- L'[Accro du casino](/docs/kruacent-exiled/custom-role/Scientist/GambleAddict) commence avec 2 pièces et en obtient d'autres avec sa capacité [Trade](/docs/kruacent-exiled/custom-ability/Trade).
- Le Middle Event [EGamble](/docs/kruacent-exiled/global-event/middle-event/EveryoneGamble) donne une pièce à tous les non-SCP.
- La [Gambling Room](gambling-room) peut en donner une.
