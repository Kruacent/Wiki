# Paramètres et commandes

Kruaçent ajoute ses propres réglages dans le menu **Paramètres du serveur** du jeu (onglet *Server-specific*). Ça vaut le coup d'y passer une fois, surtout pour régler les touches des capacités.

<Capture src={ReglagesRoles} alt="Réglages Custom Roles et Custom Items" caption="Les réglages des rôles et des objets." />

## Custom Roles

| Réglage | À quoi ça sert |
| :--- | :--- |
| **Select up / Select down** | Choisir la capacité suivante ou précédente dans votre liste. |
| **Use selected ability** | Utiliser la capacité sélectionnée. |
| **Left / Right** | Naviguer dans les menus à choix, comme les améliorations de [SCP-049-C](/docs/kruacent-exiled/custom-role/SCP/SCP049C) (flèches gauche et droite par défaut). |
| **Descriptions** | Afficher ou masquer la description de votre rôle quand vous l'obtenez. |
| **Time shown** | Combien de temps la description du rôle reste à l'écran. |
| **Ability Description time shown** | Combien de temps les messages des capacités restent à l'écran. |
| **Reshow Custom role description** | Un bouton pour réafficher la description de votre rôle. |
| **Flèche de sélection** | Personnaliser la petite flèche qui indique la capacité sélectionnée (`<--` par défaut). |

:::tip
Les touches des capacités ne sont pas réglées au départ. Pensez à les choisir avant votre première partie, sinon vos capacités ne serviront à rien.
:::

## Custom Items

| Réglage | À quoi ça sert |
| :--- | :--- |
| **Description** | Afficher ou masquer la description des objets personnalisés et leurs chances d'amélioration dans SCP-914. |
| **Pickup/Select prefixes** | Afficher la phrase complète quand vous ramassez ou sélectionnez un objet, ou seulement un petit **(P)** (ramassé) ou **(I)** (dans l'inventaire) devant son nom. |
| **Time shown** | Combien de temps le nom et la description de l'objet restent à l'écran. |
| **Time effect shown** | Combien de temps les messages d'effet des objets restent à l'écran. |

## Sound

Trois curseurs de volume, de 0 à 400 % (100 % par défaut), pour les sons ajoutés par le serveur :

- **Noise** : les bruitages (explosions, objets, capacités…).
- **Music** : les musiques (comme l'arrivée des MTF).
- **SoundBoard** : les autres sons diffusés par le serveur.

## SCP Spawn Preferences

Un curseur de **−5 à +5** pour chaque SCP, y compris les SCP personnalisés. Plus la valeur est haute, plus vous avez de chances de jouer ce SCP. Voir [l'attribution des SCP](/docs/articles/CustomRole#attribution-des-scp).

## Commandes

À taper dans la **console du jeu** (touche `²` ou `~`).

| Commande | À quoi ça sert |
| :--- | :--- |
| **`.bug <description>`** | Signaler un bug à l'équipe, en une phrase. Un signalement toutes les 2 minutes au maximum. |
| **`.rv`** (ou `.removevote`, `.retractv`, `.removev`) | Retirer votre vote pour lancer la partie, dans le lobby. Voir [Lancement de la partie](/docs/kruacent-exiled/miscellaneous/lancement-partie). |
