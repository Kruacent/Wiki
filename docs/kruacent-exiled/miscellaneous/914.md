# SCP-914

SCP-914 fonctionne comme d'habitude, avec quelques surprises en plus. Surtout si vous avez la mauvaise idée de passer **vous-même** dans la machine.

---

## Passer dans SCP-914

### L'Omni-Card
Entrez dans la machine **une carte d'accès en main**, et avec beaucoup de chance (vraiment beaucoup), elle ressort en **Omni-Card** : une carte bleue qui ouvre à peu près tout.

### Le voyage
- En **Coarse**, vous avez de bonnes chances d'être éjecté dans une salle au hasard de la **Light Containment Zone**.
- En **Fine**, très rarement, vous ressortez quelque part dans l'**Entrance Zone**.

### Le changement de rôle
Certains réglages peuvent vous faire ressortir avec un autre rôle, la plupart du temps **une fois sur deux**, et sans votre équipement :

| Vous êtes… | Réglage | Vous ressortez… |
| :--- | :--- | :--- |
| Classe-D | 1:1 | Scientifique |
| Scientifique | 1:1 | Classe-D |
| Garde | Rough | Scientifique (à coup sûr, avec un équipement de Scientifique) |
| MTF | 1:1 | Insurgé du Chaos |
| Insurgé du Chaos | 1:1 | MTF |
| SCP-049 | Rough / 1:1 | SCP-939 / SCP-106 |
| SCP-096 | 1:1 / Very Fine | SCP-3114 / SCP-939 |
| SCP-106 | Rough / 1:1 | SCP-173 / SCP-049 |
| SCP-173 | Rough / 1:1 / Very Fine | SCP-096 / SCP-939 / SCP-106 |
| SCP-939 | Rough / 1:1 / Very Fine | SCP-096 / SCP-173 / SCP-049 |
| SCP-3114 | 1:1 / Very Fine | SCP-096 / SCP-173 |

## Les objets

Quelques objets personnalisés se transforment dans SCP-914 :

| Vous mettez… | Réglage | Vous récupérez… |
| :--- | :--- | :--- |
| [Heal Zone](/docs/kruacent-exiled/custom-item/heal-zone) | 1:1 | Un [Cocktail Molotov](/docs/kruacent-exiled/custom-item/cocktail-molotov), à coup sûr |
| [Cocktail Molotov](/docs/kruacent-exiled/custom-item/cocktail-molotov) | 1:1 | Une [Heal Zone](/docs/kruacent-exiled/custom-item/heal-zone), à coup sûr |
| [Presse-Purée](/docs/kruacent-exiled/custom-item/presse-purée) | Very Fine | Rarement, une [Sainte Grenade](/docs/kruacent-exiled/custom-item/sainte-grenade) |
| [Divine Pills](/docs/kruacent-exiled/custom-item/divine-pills) | Very Fine | Parfois des [True Divine Pills](/docs/kruacent-exiled/custom-item/true-divine-pills)… parfois plus rien du tout |

La carte du [Garde de SCP-914](/docs/kruacent-exiled/custom-role/Guard/Guard914) a aussi ses propres transformations : voir sa page.

L'[Ultimate Lucky Student](/docs/kruacent-exiled/custom-role/Human/UltimateLuckyStudent), lui, ne rate jamais rien dans SCP-914 : les objets qu'il y met ressortent toujours sous leur meilleure forme.
