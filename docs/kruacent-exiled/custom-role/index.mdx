# Liste des Custom Roles

## Fonctionnement des Rôles

Les **Custom Role** sont des variations d'une classe existante (MTF, Classe-D, ...). Lorsqu'un joueur obtient un rôle personnalisé, ses caractéristiques changent.

Ces modifications peuvent être :
1.  **Statistiques :** Changement des PV max, de la vitesse ou de la taille.
2.  **Inventaire :** Apparition avec des [objets modifiés](CustomItem).
3.  **Compétences :** Ajout de [capacités](CustomAbility) actives ou passives.

### Attribution

Les rôles personnalisés sont attribués **au début de la manche** (après le choix des SCP) et **à chaque vague de renforts** :

* Chaque joueur qui n'a pas encore de rôle personnalisé en reçoit un, tiré parmi les rôles disponibles pour sa classe.
* Le tirage tient compte de la chance d'apparition de chaque rôle (100 pour la plupart des rôles). Un rôle dont la chance est de **0** n'apparaît jamais naturellement : il ne peut être donné que par un administrateur (c'est le cas du [Red Mist](/docs/kruacent-exiled/custom-role/MTF/RedMist) et de l'[Ultimate Lucky Student](/docs/kruacent-exiled/custom-role/Human/UltimateLuckyStudent)).
* Chaque rôle ne peut être attribué qu'à **un seul joueur par partie**.
* Un seul rôle **rare** peut apparaître par partie.
* Les rôles « humains » (Vieux, Sprinter, Curiosophile…) peuvent être attribués à n'importe quelle classe humaine et gardent son inventaire.

### Attribution des SCP

Les SCP personnalisés ([SCP-035](/docs/kruacent-exiled/custom-role/SCP/SCP035), [SCP-049-C](/docs/kruacent-exiled/custom-role/SCP/SCP049C)) sont tirés au sort avec les SCP de base (049, 079, 096, 106, 173, 939) quand les joueurs SCP reçoivent leur rôle :

* Chaque joueur peut régler, dans la catégorie **SCP Spawn Preferences** des paramètres du serveur, sa préférence pour chaque SCP de **−5 à +5** (0 par défaut).
* Le poids d'un SCP pour ce joueur vaut **préférence + 6**. Avec une préférence de −5, le SCP a encore un poids de 1 ; avec +5, un poids de 11.
* Un même SCP ne peut être attribué qu'une fois. Les deux premiers SCP ne peuvent pas être des SCP de soutien (SCP-079 et SCP-096), les suivants si.

## Liste des Classes Disponibles

Ci-dessous se trouve la liste des rôles présents sur le serveur :

export const RoleList = () => {
  const {items} = useCurrentSidebarCategory();

  return (
    <div>
      {items.map((item, index) => {
        
        if (item.type === 'category') {
          return (
            <div key={index} style={{marginBottom: '2rem'}}>
              {/* Titre du dossier */}
              <h3 style={{
                  borderBottom: '2px solid var(--ifm-color-primary)', 
                  paddingBottom: '0.5rem',
                  textTransform: 'uppercase',
                  color: 'var(--ifm-color-emphasis-900)'
              }}>
                {item.label}
              </h3>
              
              {/* Liste des rôles dans ce dossier */}
              <ul style={{listStyle: 'none', paddingLeft: '0'}}>
                {item.items.map((subItem, subIndex) => (
                  <li key={subIndex} style={{marginBottom: '0.5rem', paddingLeft: '1rem', borderLeft: '3px solid #333'}}>
                    <a href={subItem.href} style={{fontSize: '1.1rem', fontWeight: 'bold', textDecoration: 'none'}}>
                      {subItem.label}
                    </a>
                  </li>
                ))}
              </ul>
            </div>
          );
        }

        if (item.href && item.label !== 'Liste des Custom Roles') {
           return (
             <div key={index} style={{marginBottom: '0.5rem'}}>
                <a href={item.href}><strong>{item.label}</strong></a>
             </div>
           );
        }
        
        return null;
      })}
    </div>
  );
};
