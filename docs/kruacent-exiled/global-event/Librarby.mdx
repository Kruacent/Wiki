# Librarby

Silence, on est à la bibliothèque. Si un **humain** parle trop fort dans son micro, il explose. Pas de deuxième avertissement. Un cri, un fou rire ou un micro mal réglé suffit. Les SCP, eux, peuvent hurler autant qu'ils veulent.

Cet event n'est jamais caché derrière **[REDACTED]** : la Fondation préfère vous prévenir.
