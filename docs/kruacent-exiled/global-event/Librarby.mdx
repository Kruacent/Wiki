# Librarby

Silence dans la bibliothèque ! Tant que l'event est actif, le volume de la voix de chaque joueur est surveillé. Si un joueur **humain** parle trop fort dans son micro, il explose instantanément. Les SCP peuvent parler aussi fort qu'ils veulent.

Le seuil est atteint dès qu'un pic de volume dépasse **70 %** du volume maximal du micro : un cri, un rire ou un micro mal réglé suffit.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Ne parlez pas trop fort sinon vous subirez les conséquences ! |
| **Niveau d'impact** | Medium **[M]** |
| **Poids** | 1 |
| **Seuil de volume** | 70 % du volume maximal |
| **Joueurs concernés** | Humains uniquement |
| **Affichage [REDACTED]** | Jamais : cet event est toujours annoncé |

### Conseils

- Baissez le volume de votre micro, ou parlez doucement.
- Cet event n'est jamais caché derrière **[REDACTED]** : si l'annonce de début de partie ne le mentionne pas, il n'est pas actif.

## Note de la Fondation

Une anomalie acoustique non identifiée réagit aux voix humaines au-delà d'un certain volume. Les SCP n'y semblent pas sensibles. Le Site a adopté le règlement d'une bibliothèque, et l'applique sans exception.
