# Speed

Tout le monde va beaucoup plus vite. Une seconde après le début de la partie, **tous les joueurs** reçoivent un bonus de vitesse de déplacement d'intensité **100**, pour toute la manche. Le bonus est redonné à chaque changement de rôle (réapparition, renforts, zombies…).

Certains SCP sont aussi modifiés :

| SCP | Modification |
| :--- | :--- |
| **SCP-173** | Le temps de recharge de son clignement est divisé par **3**. |
| **SCP-939** | Quand il bondit, une grenade explose sur sa position 0,7 seconde plus tard. Elle n'inflige aucun dégât aux SCP. Il perd aussi son invisibilité quand il griffe. |
| **SCP-096** | Quand il charge, **5 grenades** explosent sur sa position, une toutes les 0,25 seconde. Elles n'infligent aucun dégât aux SCP. |

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Gas! gas! gas! |
| **Descriptions alternatives** | Super instinct! · Mayhem mode activated |
| **Niveau d'impact** | VeryHigh **[VH]** |
| **Poids** | 5 |
| **Bonus de vitesse** | Intensité 100, pour toute la partie |

### Conseils

- Gardez vos distances avec SCP-939 et SCP-096 : leurs attaques sont accompagnées d'explosions.
- SCP-173 clignote trois fois plus souvent : ne comptez pas sur le temps entre deux clignements.
