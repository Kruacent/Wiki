# ItemRain

Toutes les 120 secondes, 5 objets apparaissent dans la facilité. Pour chaque objet, une salle est tirée au sort, puis l'objet est posé sur l'un des points prédéfinis de cette salle. L'objet est tiré parmi presque tous les objets du jeu de base (armes, munitions, soins, cartes, SCP…).

Les objets suivants ne peuvent pas tomber : Micro H.I.D., Jailbird, SCP-127, 3-X Particle Disruptor, SCP-1507 (cassette), SCP-021-J, boule de neige, charbon spécial, guimauve et l'outil de débogage des ragdolls.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Il pleut des items !! |
| **Niveau d'impact** | Medium **[M]** |
| **Poids** | 1 |
| **Intervalle entre deux pluies** | 120 secondes (la première pluie tombe après 120 secondes) |
| **Objets par pluie** | 5 |

### Conseils

- Explorez les salles que vous avez déjà fouillées : de nouveaux objets peuvent y être apparus.

## Note de la Fondation

Les inventaires du Site ne correspondent plus aux registres : des équipements apparaissent dans des salles où personne ne les a déposés. Le service logistique rappelle que tout objet trouvé doit être déclaré. Personne ne l'a jamais fait.
