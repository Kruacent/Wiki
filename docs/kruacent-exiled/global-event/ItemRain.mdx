# ItemRain

Toutes les deux minutes, des objets apparaissent un peu partout dans la facilité : armes, soins, cartes, munitions, SCP… Tout peut tomber, sauf les armes vraiment trop puissantes. Une salle que vous avez fouillée il y a cinq minutes peut très bien cacher un nouveau cadeau.

## En bref

### Dans le détail

| | |
| :--- | :--- |
| **Fréquence** | Toutes les 2 minutes |
| **Combien** | 5 objets à chaque fois, dans des salles au hasard |
| **Quoi** | N'importe quel objet, sauf les plus puissants |

## Conseils

- Repassez dans les salles déjà fouillées.
- Les SCP n'ont pas besoin d'objets, mais les humains si : la partie risque de durer plus longtemps.
