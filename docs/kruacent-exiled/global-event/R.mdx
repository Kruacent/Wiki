# nothing

Cet event ne fait **rien**. La partie se joue sans modification.

Il a cependant une particularité : c'est un event **exclusif**. S'il est tiré, aucun autre Global Event n'est ajouté à la partie, même lors d'un tirage à deux events. Et s'il n'est pas tiré en premier, il ne peut plus l'être ensuite.
