# HealSCPM

*Middle Event.* Quand **tous les SCP** sont bien amochés (moins d'un tiers de leur vie environ), ils peuvent recevoir un second souffle : leur vie remonte à **la moitié**. Cet event ne peut tomber que si les SCP sont vraiment en mauvaise posture. Les zombies de SCP-049 ne sont pas concernés.

## En bref

| | |
| :--- | :--- |
| **Annonce** | *Bon aller on rallonge un peu la game* |
| **Condition** | Tous les SCP presque à terre |
| **Effet** | Les SCP remontent à la moitié de leur vie |

## Conseils

- Vous tenez les SCP à la gorge ? Finissez-les vite, avant qu'ils ne se relèvent.
