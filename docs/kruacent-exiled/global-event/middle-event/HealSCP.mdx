# HealSCPM

*Middle Event conditionnel.* Cet event ne peut être tiré que si **tous les SCP** (sauf les zombies SCP-049-2) ont **30 % de leurs PV maximum ou moins** au moment du tirage, et qu'il reste au moins un SCP.

À son activation, les PV de chaque SCP (sauf les zombies) sont remis à **la moitié de leurs PV maximum**.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Bon aller on rallonge un peu la game |
| **Poids** | 1 |
| **Condition** | Tous les SCP à 30 % de leurs PV max ou moins |
| **Effet** | PV des SCP remis à 50 % de leurs PV max |
| **SCP exclus** | SCP-049-2 |

### Conseils

- Si vous jouez les humains et que les SCP sont tous bas en vie, achevez-les vite : un SCP à 30 % peut revenir à 50 %.
