# WallHack

*Middle Event.* À son activation, **tous les joueurs** reçoivent l'effet de [SCP-1344](https://en.scpslgame.com/index.php?title=SCP-1344) : ils voient les autres joueurs à travers les murs. L'effet dure jusqu'à la fin de la partie et est redonné à chaque changement de rôle.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Tout le monde wallhack yippee!!!!! |
| **Poids** | 1 |
| **Effet** | SCP-1344, pour tous les joueurs |

### Conseils

- Tout le monde vous voit aussi : se cacher derrière une porte ne sert plus à rien.

## Note de la Fondation

Une exposition collective à un phénomène semblable à SCP-1344 a été constatée dans tout le Site. Chacun perçoit la position des autres à travers les murs. Les cachettes du Site ont perdu toute valeur.
