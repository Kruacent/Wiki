# MShuffleP

*Middle Event.* À son activation, tous les joueurs vivants échangent leur position : chacun est téléporté à l'endroit où se trouvait un autre joueur, comme dans une ronde. SCP compris. Il faut au moins 2 joueurs vivants.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Aller on change de place |
| **Poids** | 1 |
| **Joueurs concernés** | Tous les joueurs vivants, SCP compris |
| **Nombre d'échanges** | 1, au moment de l'activation |

### Conseils

- Après l'échange, regardez où vous êtes : vous pouvez vous retrouver à côté d'un SCP, ou à la place d'un SCP.

---

## Note de la Fondation

Pendant une fraction de seconde, tous les occupants du Site ont été déplacés à l'emplacement d'un autre. Aucun ne se souvient du trajet. Les registres de présence sont à refaire.
