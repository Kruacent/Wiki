# MShuffleP

*Middle Event.* Chaises musicales ! D'un coup, tous les joueurs en vie échangent leur place : chacun est téléporté là où se trouvait quelqu'un d'autre. SCP compris. Vous étiez tranquille dans un coin ? Vous voilà peut-être au milieu d'une fusillade, ou à la place de SCP-096.

## En bref

| | |
| :--- | :--- |
| **Annonce** | *Aller on change de place* |
| **Qui est concerné** | Tous les joueurs en vie |

## Conseils

- Après l'échange, regardez autour de vous avant de bouger.
