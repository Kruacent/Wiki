# SpeedM

*Middle Event.* La version mi-temps de [Speed](../Speed.mdx) : à partir de maintenant et jusqu'à la fin de la partie, **tout le monde** va beaucoup plus vite. SCP-173, lui, clignote quatre fois plus souvent.

## En bref

| | |
| :--- | :--- |
| **Annonce** | *Gas! gas! gas!* |
| **Qui est concerné** | Tout le monde |

## Conseils

- Contre SCP-173, les fenêtres pour bouger deviennent minuscules.
