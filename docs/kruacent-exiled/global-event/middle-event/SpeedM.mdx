# SpeedM

*Middle Event.* Version de milieu de partie du Global Event [Speed](../Speed.mdx). Une seconde après son activation, **tous les joueurs** reçoivent un bonus de vitesse de déplacement d'intensité **100**, jusqu'à la fin de la partie. Le bonus est redonné à chaque changement de rôle.

Le temps de recharge du clignement de **SCP-173** est divisé par **4**.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Gas! gas! gas! |
| **Poids** | 1 |
| **Bonus de vitesse** | Intensité 100 |
| **SCP-173** | Temps de recharge du clignement divisé par 4 |
| **Incompatible avec** | [Speed](../Speed.mdx) |

---

## Note de la Fondation

Un second relâchement de stimulant a été détecté dans la ventilation, en plein incident. Le personnel encore en vie court désormais plus vite. SCP-173 aussi, d'une certaine manière.
