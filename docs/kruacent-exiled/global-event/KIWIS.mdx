# KIWIS

*Kill It While It's Small.* Les SCP grossissent avec le temps. À **15 minutes** de partie, chaque SCP gagne un tiers de vie maximale en plus. À **30 minutes**, ou dès que l'ogive Alpha explose, il en regagne encore un tiers. Plus la partie traîne, plus ils deviennent des sacs à PV.

Les zombies de SCP-049 ne sont pas concernés.

### Dans le détail

| | |
| :--- | :--- |
| **À 15 minutes** | +1/3 de vie max pour chaque SCP |
| **À 30 minutes (ou à l'explosion de l'ogive)** | Encore +1/3 |
| **Zombies de SCP-049** | Pas concernés |

## Conseils

- Le nom dit tout : attaquez tôt.
- Côté SCP, jouez la montre : chaque minute vous rend plus solide.
