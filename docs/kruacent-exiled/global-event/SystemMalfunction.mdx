# System Malfunction

Les systèmes de la facilité se dérèglent. Deux pannes tournent pendant toute la partie :

1. **Ogive Alpha instable.** Toutes les minutes, il y a **5 % de chances** que l'ogive Alpha se lance d'elle-même. Cela ne peut arriver qu'une seule fois par partie. Le compte à rebours est le même que celui d'une ogive lancée normalement.
2. **Checkpoints capricieux.** Toutes les 2 à 5 minutes, une porte de checkpoint s'ouvre toute seule. La première est un checkpoint de la Light Containment Zone, les suivantes sont tirées parmi tous les checkpoints de la facilité.

### Conseils

- Une partie peut se terminer très tôt : gardez un œil sur les annonces de l'ogive.
- Ne comptez pas sur un checkpoint fermé pour vous protéger d'un SCP.

## Note de la Fondation

Le système de gestion du Site signale des erreurs en cascade. Les portes de sécurité et l'ogive Alpha reçoivent des ordres que personne n'a envoyés. Les ingénieurs sont sur place, du moins ceux qui restent.
