# System Malfunction

Les systèmes de la facilité font n'importe quoi :

- **L'ogive Alpha** peut se lancer toute seule à n'importe quel moment de la partie (une seule fois). Elle se désactive normalement, si quelqu'un a le courage d'aller la couper.
- **Les checkpoints** s'ouvrent tout seuls de temps en temps, toutes les quelques minutes.

## En bref

| | |
| :--- | :--- |
| **Annonce** | *System Malfunction* ou *La facilité marche pas trop là* |
| **Impact** | VeryLow **[VL]** |
| **Fréquence** | Rare |

## Conseils

- Une partie peut se finir très tôt : gardez une oreille sur les annonces.
- Un checkpoint fermé ne vous protège pas longtemps.
