# Blitz

Toutes les deux minutes, la facilité se fait bombarder : une volée de grenades tombe dans plusieurs salles prises au hasard. Personne ne sait où ça va taper. Si vous entendez des explosions au loin, c'est normal. Si vous les entendez de près, courez.

## En bref

| | |
| :--- | :--- |
| **Annonce** | *La Luftwaffe arrive!* ou *Attention aux bombardements!* |
| **Impact** | Low **[L]** |
| **Fréquence** | Courant |
| **Bombardement** | Toutes les 2 minutes |

## Conseils

- Ne restez pas planté au même endroit trop longtemps.
- Les SCP aussi peuvent se prendre une grenade : un bombardement bien tombé peut vous sauver la vie.
