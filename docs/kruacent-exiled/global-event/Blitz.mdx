# Blitz

Toutes les 120 secondes au cours de la partie, une vague de bombardement frappe la facilité : 5 salles sont tirées au sort, et dans chacune d'elles, une grenade explosive déjà amorcée apparaît sur chacun des points prédéfinis de la salle. Une salle tirée qui ne possède aucun point est ignorée, le nombre de grenades d'une vague varie donc.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | La Luftwaffe arrive! |
| **Description alternative** | Attention aux bombardements! |
| **Niveau d'impact** | Low **[L]** |
| **Poids** | 4 |
| **Intervalle entre deux vagues** | 120 secondes (la première vague tombe après 120 secondes) |
| **Salles tirées par vague** | 5 |

---

## Trivia

- Le terme "Blitz" vient du terme employé par les allemands durant la seconde guerre mondiale.
