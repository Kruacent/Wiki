# Fonctionnement des Global Event

Les **Global Event** sont des mutateurs qui s'active à chaque début de partie. Ils peuvent changer des statistiques des joueurs, du SCP ou ajouter des d'autres événements dans la partie.

Chaque Global Event possède un niveau d'impact qui mesure l'impact du Global Event sur la partie :
1.  **Very Low :** Impact très legers sur la partie, signalé par le préfixe **[VL]**
2.  **Low :** Légèr impact au déroulement de la partie, signalé par le préfixe **[L]**
3.  **Medium :** Impact moyen sur la partie, signalé par le préfixe **[M]**
4.  **High :** Impact élevé sur la partie, signalé par le préfixe **[H]**
5.  **Very High :** Global Event ayant un impact très élevé sur la partie, signalé par le préfixe **[VH]**
6.  **Insane :** Global Event changeant completement le cours d'une partie, signalé par le préfixe **[I]**

### Selection du Global Event

Les Global Events sont tirés au sort pendant la génération de la carte, avant le début de la partie :

* **90 %** des parties ont **un** Global Event, **10 %** en ont **deux**.
* Chaque event a un **poids** : plus il est élevé, plus l'event a de chances d'être tiré. Un event de poids 0 n'est jamais tiré au sort (seul un administrateur peut le lancer).
* Un même event ne peut pas être tiré deux fois, et deux events déclarés incompatibles ne peuvent pas être tirés ensemble.
* L'event [nothing](R.mdx) est **exclusif** : s'il est tiré, il est le seul de la partie.

Au début de la partie, les Global Events actifs sont affichés pendant 10 secondes à tous les joueurs, avec leur préfixe d'impact. Leur texte est tiré entre la description principale et les descriptions alternatives. Il y a **10 %** de chance que **[REDACTED]** soit affiché à la place du texte d'un event (sauf pour [Librarby](Librarby.mdx), qui est toujours annoncé).

:::note Valeurs par défaut
Les poids indiqués sur ce wiki sont les valeurs par défaut du code. Le serveur peut les modifier dans un fichier de configuration.
:::

## Middle Events

Les **Middle Events** fonctionnent comme les Global Events, mais se déclenchent **en cours de partie** au lieu du début :

* Au début de chaque partie, il y a **37 %** de chance que la partie ait un Middle Event.
* Si c'est le cas, un moment d'activation est tiré entre **10 et 15 minutes** de partie. Le jeu vérifie chaque minute si ce moment est passé : le Middle Event se déclenche donc entre 10 et 16 minutes environ.
* Il y a **au maximum un** Middle Event par partie. Il est tiré au sort selon les poids, au moment de l'activation.
* Certains Middle Events ont une **condition** : ils ne peuvent être tirés que si elle est remplie au moment du tirage.
* À l'activation, le Middle Event est annoncé pendant 10 secondes (« Middle Event : » suivi de sa description). Les Middle Events n'ont pas de niveau d'impact et ne sont jamais cachés derrière **[REDACTED]**.

| Middle Event | Poids | Condition |
| :--- | :--- | :--- |
| [EGamble](middle-event/EveryoneGamble.mdx) | 1 | Aucune |
| [HealSCPM](middle-event/HealSCP.mdx) | 1 | Tous les SCP à 30 % de leurs PV max ou moins |
| [MShuffleP](middle-event/ShufflePosition.mdx) | 1 | Aucune |
| [SpeedM](middle-event/SpeedM.mdx) | 1 | Aucune |
| [WallHack](middle-event/WallHackM.mdx) | 1 | Aucune |

## Liste des Global Events Disponibles

Ci-dessous se trouve la liste des Global Events présent sur le serveur :

export const RoleList = () => {
  const {items} = useCurrentSidebarCategory();

  return (
    <div>
      {items.map((item, index) => {
        
        if (item.type === 'category') {
          return (
            <div key={index} style={{marginBottom: '2rem'}}>
              <h3 style={{
                  borderBottom: '2px solid var(--ifm-color-primary)', 
                  paddingBottom: '0.5rem',
                  textTransform: 'uppercase',
                  color: 'var(--ifm-color-emphasis-900)'
              }}>
                {item.label}
              </h3>
              
              <ul style={{listStyle: 'none', paddingLeft: '0'}}>
                {item.items.map((subItem, subIndex) => (
                  <li key={subIndex} style={{marginBottom: '0.5rem', paddingLeft: '1rem', borderLeft: '3px solid #333'}}>
                    <a href={subItem.href} style={{fontSize: '1.1rem', fontWeight: 'bold', textDecoration: 'none'}}>
                      {subItem.label}
                    </a>
                  </li>
                ))}
              </ul>
            </div>
          );
        }

        if (item.href && item.label !== 'Liste des Custom Roles') {
           return (
             <div key={index} style={{marginBottom: '0.5rem'}}>
                <a href={item.href}><strong>{item.label}</strong></a>
             </div>
           );
        }
        
        return null;
      })}
    </div>
  );
};

<RoleList />
