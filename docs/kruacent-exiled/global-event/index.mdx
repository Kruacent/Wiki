# Global Events

Au début de chaque partie, la Fondation tire une **règle spéciale** : c'est le Global Event. Il s'affiche à l'écran dès le lancement, avec son niveau d'impact entre crochets.

## Tous les Global Events

Du plus courant au plus rare.

<GlobalEventTable />

**Niveaux d'impact :** **[VL]** à peine visible, **[L]** léger, **[M]** moyen, **[H]** gros changement, **[VH]** la partie part en vrille, **[I]** tout est permis.

## Middle Events

Les surprises de mi-temps. Dans un peu plus d'**une partie sur trois** (<ChanceMiddleEvent />), un Middle Event tombe **entre 10 et 16 minutes** de jeu pour relancer la partie. Un seul par partie, et il dure jusqu'à la fin.

Le Middle Event est tiré au sort **au moment où il tombe**. Un event soumis à une condition, comme [HealSCPM](/docs/kruacent-exiled/global-event/middle-event/HealSCP), n'entre dans le tirage que si sa condition est remplie à cet instant précis. Sinon, il est retiré du tirage et les autres se partagent sa chance.

<MiddleEventTable />

:::danger Obsolète
**MShuffleI** (mélange des inventaires) et **MShuffle** (mélange des rôles) ne tombent plus.
:::

## Liste des Global Events Disponibles

Ci-dessous se trouve la liste des Global Events présents sur le serveur :

export const RoleList = () => {
  const {items} = useCurrentSidebarCategory();

  return (
    <div>
      {items.map((item, index) => {
        
        if (item.type === 'category') {
          return (
            <div key={index} style={{marginBottom: '2rem'}}>
              <h3 style={{
                  borderBottom: '2px solid var(--ifm-color-primary)', 
                  paddingBottom: '0.5rem',
                  textTransform: 'uppercase',
                  color: 'var(--ifm-color-emphasis-900)'
              }}>
                {item.label}
              </h3>
              
              <ul style={{listStyle: 'none', paddingLeft: '0'}}>
                {item.items.map((subItem, subIndex) => (
                  <li key={subIndex} style={{marginBottom: '0.5rem', paddingLeft: '1rem', borderLeft: '3px solid #333'}}>
                    <a href={subItem.href} style={{fontSize: '1.1rem', fontWeight: 'bold', textDecoration: 'none'}}>
                      {subItem.label}
                    </a>
                  </li>
                ))}
              </ul>
            </div>
          );
        }

        if (item.href && item.label !== 'Liste des Custom Roles') {
           return (
             <div key={index} style={{marginBottom: '0.5rem'}}>
                <a href={item.href}><strong>{item.label}</strong></a>
             </div>
           );
        }
        
        return null;
      })}
    </div>
  );
};
