# Kaboom

Les portes de la facilité sont piégées. Chaque fois qu'un joueur **ferme une porte ouverte**, il y a une chance qu'une grenade explosive amorcée apparaisse à ses pieds. Ouvrir une porte fermée ne déclenche jamais le piège.

La chance dépend du type de porte :

| Type de porte | Chance de piège |
| :--- | :--- |
| **Ascenseur** | 5 % |
| **Gate** | 50 % |
| **Porte destructible (porte classique)** | 10 % |

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Les portes sont piegés attention! |
| **Description alternative** | La guerrilla est présente |
| **Niveau d'impact** | Medium **[M]** |
| **Poids** | 2 |
| **Dégâts sur les SCP** | Moitié des dégâts normaux d'une grenade |

### Conseils

- Laissez les portes ouvertes derrière vous plutôt que de les refermer.
- Si vous devez fermer une Gate, éloignez-vous tout de suite : une fois sur deux, une grenade apparaît.
