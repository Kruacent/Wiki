# Kaboom

Les portes sont piégées. **Ouvrir** une porte, aucun souci. Mais quand vous **refermez** une porte, il arrive qu'une grenade apparaisse à vos pieds. Les Gates sont les pires : une fois sur deux, ça pète. Les ascenseurs sont presque sûrs, les portes normales un peu moins.

Petite consolation : les grenades font moins mal aux SCP qu'aux humains.

### Dans le détail

| | |
| :--- | :--- |
| **Quand** | En **refermant** une porte (ouvrir ne risque rien) |
| **Gate** | 1 fois sur 2 |
| **Porte normale** | 1 fois sur 10 |
| **Ascenseur** | 1 fois sur 20 |
| **SCP** | Prennent moitié moins de dégâts |

## Conseils

- Laissez les portes ouvertes derrière vous. Votre maman ne vous en voudra pas.
- Si vous devez fermer une Gate, fermez et courez.
