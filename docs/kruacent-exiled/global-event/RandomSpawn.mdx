# RandomSpawn

Au début de la partie, les points d'apparition sont mélangés. Pour **chaque rôle**, une salle est tirée au sort, et tous les joueurs qui ont ce rôle y sont téléportés. Tous les Classe-D apparaissent donc ensemble dans une même salle, tous les Scientifiques ensemble dans une autre, et chaque SCP dans sa propre salle.

La salle peut se trouver dans n'importe quelle zone, sauf les salles de la Gate A et de la Gate B. Seule l'apparition de début de partie est concernée : les renforts (MTF, Insurrection du Chaos) apparaissent normalement.

| Paramètre | Valeur |
| :--- | :--- |
| **Description** | Les spawns sont random |
| **Niveau d'impact** | High **[H]** |
| **Poids** | 5 |
| **Moment** | Début de la partie uniquement |
| **Salles exclues** | Gate A, Gate B |

### Conseils

- Regardez autour de vous dès l'apparition : vous ne savez pas dans quelle zone vous êtes, ni quel SCP est à côté.
- Restez avec les joueurs de votre rôle : vous êtes apparus au même endroit.

## Note de la Fondation

Le système de transfert du personnel a dysfonctionné pendant la relève : chaque équipe a été envoyée dans une salle prise au hasard. Les anomalies aussi. Les plans d'évacuation habituels ne s'appliquent plus.
