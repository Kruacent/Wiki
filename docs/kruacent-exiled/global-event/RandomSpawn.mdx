# RandomSpawn

Au début de la partie, personne n'apparaît là où il devrait. Chaque rôle est envoyé dans une salle prise au hasard, n'importe où dans la facilité. Tous les joueurs d'un même rôle arrivent ensemble : les Classe-D d'un côté, les Scientifiques de l'autre, et chaque SCP dans son coin.

Seul le début de partie est concerné : les renforts arrivent normalement.

## En bref

| | |
| :--- | :--- |
| **Annonce** | *Les spawns sont random* |
| **Impact** | High **[H]** |
| **Fréquence** | Courant |

## Conseils

- Regardez autour de vous avant de foncer : vous ne savez pas où vous êtes, ni qui est dans la salle d'à côté.
- Restez avec vos collègues : vous êtes tous arrivés au même endroit.
