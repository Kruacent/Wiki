# OpenBar

C'est open bar. Dès le début de la partie, la **Gate A** et la **Gate B** sont grandes ouvertes, ainsi que **trois autres portes** prises au hasard parmi les salles importantes (armureries, Intercom, salles de SCP, SCP-914…). Ces portes restent bloquées ouvertes jusqu'à la fin : impossible de les refermer.

Les campeurs vont devoir trouver un autre plan.

## Conseils

- Faites le tour des salles ouvertes : une armurerie ouverte, c'est du matériel gratuit.
- Les SCP ont un accès direct en Surface : ne comptez pas sur les Gates pour les arrêter.
