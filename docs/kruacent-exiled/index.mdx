**Kruaçent-Exiled** est un plugin développé pour le jeu *SCP: Secret Laboratory*. Divisée en quatre modules, chacun ayant pour objectifs d'enrichir les mécaniques de base du jeu afin d'offrir une meilleure expérience aux joueurs.

## Rôles personnalisés

Ce module introduit de nouvelles sous-rôles jouables, pour les humains mais également pour les SCPs. 

*   **Pour les humains :** Rôles permettant d'avoir des caractéristiques ou habilités spécifiques.
*   **Pour les SCPs :** Rôles permettant d'avoir des caractéristique différentes (être plus petit, plus fin...).
*   **Nouveaux SCPs :** Ajout de nouveaux SCP comme SCP-035.

## Objets personnalisés

Le module d'objets ajoute des équipements utiles pour les humains.

*   Divers objets de soin, objets tactiques, grenades...

## Événements globaux

Afin d'éviter la répétition des parties, ce module permet d'avoir une règle qui change en début de oartie.

*   Un ou plusieurs événement est révélé à l'ensemble des joueurs au début du round.
*   Les modifications peuvent impacter n'importe quelles aspect du jeu.

## Ajouts divers

Ce module regroupe plusieurs changement qui améliore divers point ne mériant pas un module complet à eux seul.

*   **Pièce magique :** Donne un effet aléatoire à chaque lancer de pièce.
*   **Autre ajout:** Ajout d'ascenseurs autonomes...

---

## Installation

Pour installer ce plugin sur votre serveur, il est nécessaire de placer le fichier compilé dans le répertoire standard d'Exiled.

1.  Téléchargez la dernière version compilée depuis GitHub.
2.  Placez le fichier `.dll` dans le répertoire `Exiled/Plugins`.
3.  Redémarrez le serveur pour initialiser les modules.

[Télécharger la dernière version](https://github.com/Kruacent/Kruacent-Exiled/releases)
