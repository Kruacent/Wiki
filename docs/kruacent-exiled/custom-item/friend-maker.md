# Friend Maker™

Le **Friend Maker™** est un COM-15 qui ne blesse pas : il **recrute**. Une balle qui touche un joueur ne fait aucun dégât, mais le transforme en membre du rôle du tireur :

- **Zombie (SCP-049-2) :** il devient un membre du rôle du tireur et reçoit l'inventaire de ce rôle.
- **Humain d'un autre camp :** il devient lui aussi un membre du rôle du tireur, mais garde son inventaire.
- **Allié** ou **SCP autre qu'un zombie :** rien ne se passe, un message l'indique.

Après une conversion réussie, l'arme ne peut plus tirer pendant **60 secondes** (un message affiche le temps restant).

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | LA méthode pour se faire des amis ! Produit non remboursable |
| **Description (Anglais)** | The number one (1) method to make friends |
| **Objet de base** | COM-15 |
| **Chargeur** | 1 balle |
| **Poids** | 1 |
| **Rareté** | Épique |
| **Temps de recharge** | 60 secondes après une conversion |

## Messages

| Situation | Message (FR) |
| :--- | :--- |
| Personne touché | Mais personne n'est venu |
| Allié | Je sais que tu l'aime pas mais il est bien avec toi |
| SCP (pas un zombie) | C'est pas un zombie ça |
| Réussite | Nouvel ami obtenu! |

## Obtention

Il n'apparaît pas dans la facilité : le [Négociateur](/docs/kruacent-exiled/custom-role/ChaosInsurgency/Negotiator) commence la partie avec.

## Note de la Fondation

Un pistolet modifié qui remplace le projectile par un argument très convaincant. Les cibles touchées changent immédiatement de camp. Le service juridique de l'Insurrection affirme que le produit n'est pas remboursable.
