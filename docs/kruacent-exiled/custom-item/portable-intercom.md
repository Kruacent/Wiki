# SCP-1065-KR : « Intercom Portable »

L'**Intercom Portable** est une radio qui permet de parler **à toute la facilité, comme à l'Intercom**, où que l'on soit. Il suffit de parler en l'ayant en main.

## Fonctionnement

- Une prise de parole dure **10 secondes** au maximum. Au-delà, elle est coupée.
- Après chaque diffusion, il faut attendre **90 secondes** avant de recommencer (un message affiche le temps restant).
- Impossible de l'utiliser si l'Intercom est déjà occupé.

## Caractéristiques

| Paramètre | Valeur |
| :--- | :--- |
| **Description (Français)** | Tu peux parler à Intercom |
| **Description (Anglais)** | You can talk at the intercom |
| **Objet de base** | Radio |
| **Poids** | 0,5 |
| **Rareté** | Légendaire |
| **Durée maximale** | 10 secondes |
| **Temps de recharge** | 90 secondes |
| **Limite** | 1 |

## Localisation

| Lieu | Chance d'apparition |

## Note de la Fondation

Une radio modifiée reliée directement au système de diffusion du Site. Son usage est limité pour éviter que le réseau ne soit saturé. La direction rappelle qu'il ne sert pas à chanter.
