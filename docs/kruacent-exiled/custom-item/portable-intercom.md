# Intercom Portable

L'**Intercom Portable** est une radio qui permet de parler **à toute la facilité, comme à l'Intercom**, où que l'on soit. Il suffit de parler en l'ayant en main : la diffusion commence avec le son de l'Intercom.

## Fonctionnement

- La diffusion s'arrête **0,35 seconde** après que vous arrêtez de parler.
- Une prise de parole dure **10 secondes** au maximum. Au-delà, elle est coupée (*"Ohhh tu parles trop là"*).
- Après chaque diffusion, il faut attendre **90 secondes** avant de recommencer (un message affiche le temps restant).
- Impossible de l'utiliser si l'Intercom est déjà occupé (*"Intercom est déjà en cours d'utilisation"*).
- Il ne fonctionne pas comme une radio : l'allumer affiche *"Ceci n'est pas une radio mais un intercom portable"*.
